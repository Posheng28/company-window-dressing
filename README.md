# 近10年集團作帳行情研究

台股 68 個集團、368 檔上市櫃成員股，檢驗 3／6／9／12 月「作帳行情」是否存在。

**線上閱讀**：https://posheng28.github.io/company-window-dressing/

## 這份研究在做什麼

- 統計期間：2016/01–2026/06
- 窗口定義：前月 1 日進場、結帳月底出場（例：12 月窗＝11/1–12/31）
- 基準：加權股價報酬指數、櫃買報酬指數
- 價格：FinMind `TaiwanStockPriceAdj` 還原收盤價（含息）

內容包含四個作帳窗的集團排行、不綁死出場日的窗內峰值分析、可選集團的逐年專區、
每一年每一檔成員股的曲線瀏覽器，以及含交易成本的回測與「不偷看答案」的走出樣本驗證。
